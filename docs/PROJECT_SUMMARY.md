# Project Summary — OpenDiscourse

## What This Is

OpenDisourse is a long-lived research platform for collecting, structuring, and analyzing public governance data at scale.

It is designed to:
- Ingest large volumes of government documents safely
- Preserve original source material
- Enable longitudinal and comparative analysis
- Support AI-assisted exploration without hallucination

## Current Phase

**Phase 1: Foundation & Ingestion**

Completed / In Progress:
- Canonical schema planning
- PostgreSQL as primary metadata store
- File-based document storage strategy
- Ingestion run tracking (planned)
- Resume-safe ingestion design

## Immediate Priorities

1. Finalize PostgreSQL schema
2. Implement govinfo.gov ingestion
3. Store raw documents safely
4. Add OCR + text extraction pipeline
5. Track ingestion runs and checkpoints

## Long-Term Vision

- Multi-source normalized governance dataset
- Full-text search + embeddings
- RAG-backed research assistants
- Transparency dashboards
- Exportable, reproducible analysis
